POSTING
1. Choose one draft and its paired MP4 or PNG in posting-guide.txt.
2. Open your platform's composer and paste the draft.
3. Attach the matching file yourself. Copying text does not attach media.
4. Add the supplied description to a PNG's alt-text field. For the film, use its description or transcript where supported.
5. Preview the attachment, wording, and website link before publishing.

The drafts use the creator's voice; adjust that wording if sharing as someone else. Recheck length after edits. This kit does not upload, post, open an account, or request credentials.
