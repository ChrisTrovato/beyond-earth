# Sources, media, and development

The application was directed by the repository owner and developed with substantial OpenAI Codex assistance. Source and implementation are published for inspection, learning, and portfolio documentation.

Primary engineering references are linked in each lesson. The book bibliography is in `site/data/sources.json` and the rendered Sources section. The book and worked examples form a general-audience teaching resource; MERIDIAN is a fictional settlement case.

Cinematic environment artwork and launch illustrations were generated with AI. `docs/launch/image-prompts.txt` contains the two launch-art prompts. The SVG/canvas diagrams and simulation visuals are generated by application code. `site/assets/social/v4/03-beyond-earth-in-motion.mp4` is a silent capture of the actual site activities, edited into a 26-second introduction.

Reel footage remains with the original publishers. `site/data/reels.json` identifies speakers, titles, sources, and original video links. The repository embeds or links publisher-hosted video; it does not distribute copies of those talks or imply speaker endorsement.

No blanket license for third-party publications or video is implied by this repository. A separate open-source/content license has not been selected for this initial project import.
